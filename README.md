# Lyondle

**Lyondle is a trilogy of games based on the Métropole of Lyon's transit 
network.**

[Check it out here](https://lyondle.fr/)

### How does it works ?

Under the hood (out of this repo), I developed a database and ingestion system
called **Colosse** _(In Memoriam of Titan)_ allowing my games and back-ends to
interact with up-to-date, cleaned-up, and enriched datasets.

[Try Colosse](https://johanmontorfano.com/blog/7ecf765c-143f-43e0-b252-64191d08527c)
